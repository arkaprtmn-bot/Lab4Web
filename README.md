Bagian Kepala & Setting Dasar (<head>): Ini ibarat fondasi awal file HTML-nya. Ada meta charset="UTF-8" biar teks sama emoji monyet nggak error atau berantakan, viewport biar pas dibuka di HP atau laptop tampilannya nggak jomplang, sama link rel="stylesheet" buat nyambungin ke file CSS (style.css) supaya webnya punya warna dan bentuk kotak-kotak yang rapi.

Judul Web (<header>): Cuma buat naruh judul utama web di paling atas, contohnya "JUAL BELI MONYET" biar langsung kelihatan toko apa ini pas dibuka.

Menu Navigasi (<nav>): Nah, ini tombol-tombol menu di atas (Home, Artikel, About, Kontak). Pakai tag <a> dengan atribut href tujuannya buat jalur perpindahan file, jadi pas diklik ya larinya ke file html yang dituju.

Banner Promo (<section id="hero">): Kotak sambutan paling atas yang agak lebar. Biasanya dipake buat naruh teks promo minggu ini sama tombol "Belanja Sekarang" biar kelihatan kaya e-commerce beneran.

Katalog Produk (<div class="row"> & <div class="box">): Ini wadah buat mangpangin foto-foto monyetnya (jinak, galak, sawit) jejer ke samping biar rapi. Di dalam box-nya ada foto lingkaran, judul, deskripsi singkat, sama tombol detail.

Garis Pemisah (<hr>): Biar gampangannya, ini cuma bikin garis lurus tipis melintang buat misahin antara bagian katalog atas sama artikel di bawahnya biar nggak numpuk.

Bagian Artikel (<article>): Tempat naruh info atau tips tambahan (kayak cara ngerawat monyet). Dilengkapi CSS right-img biar fotonya bisa nangkring rapi di sebelah kanan teks.

Sidebar Kanan (<aside>): Kolom tambahan di sebelah kanan yang isinya widget-widget penting, kayak list keperluan monyet pakai <ul> dan <li>, plus catatan penting buat pengunjung.

Kaki Web (<footer>): Bagian paling bawah halaman yang biasanya dipake buat naruh copyright, misal © 2026 - Universitas Pelita Bangsa.
